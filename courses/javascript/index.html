Comprehensive Curriculum

Complete Course Syllabus

Structured modular learning path from foundational concepts to production-grade implementation.

Module 1: Engine Execution, Scopes & Closures

Weeks 1-2
  • ✓ V8 engine architecture
  • ✓ Execution context and Call Stack
  • ✓ Hoisting and Temporal Dead Zone
  • ✓ Scope chain and Lexical Closures

Module 2: Prototypes & Object-Oriented JS

Weeks 3-4
  • ✓ Prototypal inheritance and Prototype chain
  • ✓ ES6 Classes and constructors
  • ✓ Object methods and Property descriptors
  • ✓ this keyword binding rules

Module 3: Asynchronous JS & The Event Loop

Weeks 5-6
  • ✓ Event Loop: Macrotask vs Microtask queues
  • ✓ Promises and Promise combinators (all, allSettled, race)
  • ✓ async/await syntax and error handling
  • ✓ Fetch API and HTTP communication

Module 4: DOM Architecture & Modern Browser APIs

Weeks 7-8
  • ✓ DOM tree traversal and manipulation
  • ✓ Event bubbling, capturing, and delegation
  • ✓ Web Storage and IndexedDB overview
  • ✓ Performance: Debouncing and Throttling
